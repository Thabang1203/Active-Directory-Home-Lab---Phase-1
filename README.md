# Active Directory Home Lab - Phase 1

## Overview
This project documents the setup of a Windows Server 2025 Active Directory home lab using Oracle VirtualBox. The goal is to gain hands-on experience with Windows Server administration and Active Directory Domain Services (AD DS).

## Phase 1 Objectives
- Download and install Windows Server 2025 Evaluation.
- Create and configure a virtual machine using VirtualBox.
- Install the Active Directory Domain Services (AD DS) role.
- Prepare the server for Domain Controller promotion.
- Document all activities with screenshots and notes.

## Environment
- **Hypervisor:** Oracle VirtualBox
- **Operating System:** Windows Server 2025 Standard Evaluation
- **Server Name:** VMHomeLab (renaming to UDA-DC01 planned)
- **Planned Domain:** `ubuntudigital.local`
