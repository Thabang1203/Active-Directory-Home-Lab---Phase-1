# Active Directory Home Lab - Phase 1

## Overview

A hands-on Windows Server home lab focused on building the foundation for an **Active Directory Domain Services (AD DS)** environment using Oracle VirtualBox.

The project demonstrates practical experience with Windows Server installation, virtual machine configuration, Active Directory deployment, and domain infrastructure preparation.

## Environment

- **Hypervisor:** Oracle VirtualBox
- **Operating System:** Windows Server 2025 Standard Evaluation
- **Server:** VMHomeLab
- **Domain:** `ubuntudigital.local`

## Tasks Completed

- Created and configured a Windows Server virtual machine
- Installed Windows Server 2025
- Configured the server through Server Manager
- Installed the Active Directory Domain Services (AD DS) role
- Installed Active Directory management tools
- Started Domain Controller configuration
- Planned DNS and domain settings
- Documented the implementation with screenshots

## Skills Demonstrated

`Windows Server` `Active Directory` `AD DS` `VirtualBox` `DNS` `Server Administration` `Domain Controllers` `Virtualization` `Technical Documentation`

## Next Phase

Phase 2 focuses on:

- Domain Controller promotion
- Creating the `ubuntudigital.local` forest
- Configuring Organizational Units (OUs)
- Creating security groups and user accounts
- Managing users and group memberships
- Practicing Active Directory user lifecycle management

## Learning Outcome

This phase provided practical experience in deploying Windows Server and preparing an Active Directory infrastructure for identity, access, and user management.
